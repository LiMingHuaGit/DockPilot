Core features

Two modes, one switch

Automatic when you want it, pinned when you don't — all from the menu bar.

🧭

Follow the cursor

Wherever your cursor settles, the Dock follows. An adjustable delay (0.2–1.2s) avoids accidental switches when you just pass through.

📌

Pin to a display

Lock the Dock to the monitor you pick. It's remembered by a stable display ID, so it stays put across sleep and reconnects.

🔓

No system permissions

No Accessibility permission required. Cursor tracking polls a public API, and screen switching uses the public display-configuration API.

▫️

Lives in the menu bar

A background app with no Dock icon. The menu shows the current mode at a glance — switch anytime, launch at login.

How it works

How it actually works

macOS has no public API to move only the Dock. The Dock and the menu bar both belong to the main display, so DockPilot brings the Dock over by making the target screen the main display — the menu bar moves along with it. That's the accepted trade-off for reliable behavior.
STEP 01

Detect the cursor's screen

Polls the cursor position to tell which display you're working on.

STEP 02

Set it as main

Makes the target screen the main display via CoreGraphics — no special permission.

STEP 03

The Dock follows

The Dock and menu bar appear on the screen you're using.
